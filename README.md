# SD PCT Jhonsen

Repository pembelajaran Algoritma dan Struktur Data serta latihan Git CLI melalui PowerShell.

**Repository:** [jhonboe93/sd-pct-jhonsen](https://github.com/jhonboe93/sd-pct-jhonsen)

## Mulai latihan

```powershell
git clone https://github.com/jhonboe93/sd-pct-jhonsen.git
cd sd-pct-jhonsen
git status
```

Jika sudah pernah clone, buka folder `sd-pct-jhonsen` di PowerShell dan jalankan `git status`.
